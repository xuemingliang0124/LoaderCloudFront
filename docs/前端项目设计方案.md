## 一、后端契约速览（前端实现唯一事实源）

> 以下契约来自后端 [main.py](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/main.py)、[api/v1/__init__.py](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/api/v1/__init__.py)、[schemas/common.py](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/schemas/common.py)、[api/deps.py](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/api/deps.py) 等真实源码，非推断。

### 1.1 路由前缀与挂载

- 业务 API 统一前缀 `/api/v1`（[main.py:75](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/main.py#L75)）
- WS 路由独立挂载（[main.py:76](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/main.py#L76)），`/ws/agent` 为 Agent→Master 专用通道，**浏览器不可连**

### 1.2 统一响应与错误

| 情况 | HTTP | Body | 前端处理 |
|---|---|---|---|
| 正常 | 200 | `{code:0, message:"ok", data:...}` | 响应拦截器直接返回 `data` |
| 业务错误 `BusinessError` | 400 | `{code:非0, message:..., data:null}` | 拦截器抛错 + ElMessage |
| 未登录 / token 失效 | 401 | **FastAPI 默认 `{"detail":"未登录"}`**（非统一格式） | 拦截器按 `status===401` 判定，登出 + 跳登录 |
| 其他 HTTP 错误 | 4xx/5xx | 不定 | 提示「网络异常」兜底 |

> **关键坑**：401 响应体是 FastAPI 默认 `{detail}`，**不是** `{code,message,data}`。前端拦截器在错误分支必须先判 HTTP status，再尝试读 `body.message`，绝不能假设 401 也走统一响应。

### 1.3 鉴权

- `POST /api/v1/auth/login`（[auth.py:15](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/api/v1/auth.py#L15)）
  - 请求：`{username, password}`
  - 响应 data：`{token, username, role}`
- 后续请求头：`Authorization: Bearer <token>`，后端用 `HTTPBearer` 解析（[deps.py:8](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/api/deps.py#L8)）
- 默认账号：`admin / admin123`（后端 `ensure_default_user` 兜底创建）
- role 字段后端已返回但路由未做权限分层，前端菜单暂全显示，预留 `v-if="auth.role==='admin'"`

### 1.5 分页约定

- 仅 `GET /runs` 支持分页：`page`（默认 1，≥1）、`page_size`（默认 20，1~100）（[common.py:13](file:///d:/PycharmProjects/LoaderCloudBackendV2/master/app/schemas/common.py#L13)）
- 响应：`{total: number, items: RunOut[]}`
- 其余列表端点（agents/scripts/scenarios/schedules）**后端不分页**，一次性返回数组，前端直接 `el-table` 渲染，不挂 `el-pagination`

### 1.6 字段命名

- 后端 Pydantic 全 snake_case：`run_no`/`agent_id`/`created_at`/`cpu_percent`/`mem_percent`/`jmeter_version`/`file_key`/`scenario_id`/`agent_tags`/`param_overrides`/`last_run_no` 等
- 前端 TS 类型直接用 snake_case，**禁止**做驼峰转换，省一层心智负担与双向映射

## 二、技术栈选型

> 项目记忆已锁定：**Vue3 + Element Plus + ECharts**。下列为补全选型。

| 维度 | 选型 | 理由 |
|---|---|---|
| 框架 | Vue 3 + `<script setup>` + TypeScript | 响应式 + 类型安全 |
| 构建 | Vite 5 | 与后端 dev proxy 直连 8000 |
| UI | Element Plus（按需自动导入） | 表单/表格/分页组件齐全，匹配后台管理场景 |
| 图标 | @element-plus/icons-vue | 与 EP 一致 |
| 图表 | ECharts 5（直连 `echarts`，非 vue-echarts） | 实时曲线控件可控；RunDetail 用裸 `echarts.init` |
| 路由 | vue-router 4（history 模式） | 守卫做登录拦截 |
| 状态 | Pinia（setup 风格） | 鉴权态最轻量 |
| HTTP | axios + 拦截器 | 统一响应拆包、401 处理 |
| 样式 | sass + Element Plus 主题变量 | 不污染全局 |
| 自动导入 | unplugin-auto-import + unplugin-vue-components | EP 按需、Vue API 自动导 |

不引入：`vue-echarts`（包了一层反而限制实时控制）、`vuex`（已过时）、`axios-retry`（后端无重试语义）。

### 4.2 路由守卫

- `meta.public = true` 标记登录页
- `beforeEach`：非 public 且无 token → `router.push('/login?redirect=...')`
- 登录成功后读 `redirect` query 跳回原页

### 4.3 页面职责

- **Login.vue**：表单（用户名/密码）→ `authStore.login()` → 跳 `redirect` 或 `/agents`；预填 `admin/admin123` 仅 dev 环境
- **AgentList.vue**：`el-table` 渲染 `GET /agents` 返回数组；状态/心跳/CPU/内存可视化（小进度条或 tag）；无需分页
- **ScriptList.vue**：上传对话框（`el-upload` JMX + 多数据文件 + params JSON 编辑器）+ 列表表格；不分页
- **ScenarioList.vue**：新建对话框（关联 script_id、agent_tags、agent_count、duration、param_overrides）+ 列表；不分页
- **RunList.vue**：`el-pagination` 翻页（唯一分页）；每行「停止」按钮（status 为 RUNNING/PENDING 时可用）+ 「查看详情」跳 `/runs/:runNo`；顶部「新建运行」对话框（选 scenario_id + 可选 agent_ids）
- **RunDetail.vue**：`echarts.init` 实时 TPS 曲线，5s 轮询 `GET /metrics/timeseries`，`xAxis.type='time'`，多 label series；组件卸载 `dispose` + 清 timer
- **ScheduleList.vue**：列表 + 新建对话框（cron 校验交给后端 4001）+ 启停开关（调 `toggle`）

## 五、核心模块设计

### 5.1 axios 实例与拦截器（`src/api/request.ts`）

**请求拦截器**：从 `authStore` 读 token，注入 `Authorization: Bearer <token>`。

**响应拦截器（成功分支）**：
1. 读 `body = resp.data` 为 `ApiResponse`
2. `body.code === 0` → 返回 `body.data`（直接被调用方拿到业务数据）
3. `body.code !== 0` → `ElMessage.error(body.message)` + `reject`（兜底，正常业务错误走 HTTP 400）

**响应拦截器（错误分支）**：
1. **优先判 HTTP status**：
   - `401` → `authStore.logout()` → `router.push('/login?redirect=...')`；**不弹 ElMessage**（避免与后续登录页叠加）
   - `400` 且 `err.response.data.code` 存在 → `ElMessage.error(err.response.data.message)`（业务错误）
   - 其他 → `ElMessage.error(err.response?.data?.message || err.message || '网络异常')`
2. 始终 `reject(err)`

> 实现注意：`router` 与 `useAuthStore` 都在拦截器里懒调，避免循环依赖（Pinia 实例必须先 `app.use(pinia)`）。

### 5.2 鉴权 Store（`src/stores/auth.ts`）

- `token/username/role` 三个 `ref`，初始值读 `localStorage`
- localStorage key 约定：`ptp_token` / `ptp_user` / `ptp_role`（与项目代号 ptp 一致）
- `login(payload)` 调 `POST /auth/login`，写 state + localStorage
- `logout()` 清 state + localStorage

### 5.3 API 层（`src/api/*.ts`）

**一资源一文件**，函数签名直接给泛型：
- `request.get<unknown, PageResult<Run>>('/runs', { params: { page, page_size } })`
- `request.post<unknown, { run_no: string; agent_ids: string[] }>('/runs', { scenario_id, agent_ids })`
- `listAgents()` 返回 `Promise<Agent[]>`（无分页）
- `uploadScript(formData)` 用 `request.post('/scripts', formData, { headers: {'Content-Type':'multipart/form-data'} })`
- `getTimeseries(run_no, start, end, interval=15)` 返回 `Promise<TimeseriesPoint[]>`

### 5.4 类型层（`src/types/api.ts`）

镜像后端 Pydantic，字段全 snake_case：
- `ApiResponse<T>` / `PageResult<T>`
- `LoginIn` / `LoginOut`
- `Agent` / `Run` / `Script` / `Scenario` / `Schedule` / `TimeseriesPoint`

### 5.5 ECharts 实时曲线（`RunDetail.vue`）

- `onMounted`：`echarts.init(chartRef.value)` → 首次 `poll()` → `setInterval(poll, 5000)`
- `poll`：`end = Math.floor(Date.now()/1000)`、`start = end - 300`（最近 5 分钟）→ `getTimeseries` → 按 `label` 分组生成 series
- `setOption`：`tooltip.trigger='axis'`、`legend.type='scroll'`、`xAxis.type='time'`、`yAxis` 按 TPS
- `onBeforeUnmount`：`clearInterval(timer)` + `chart.dispose()`

### 5.6 dev proxy（`vite.config.ts`）

- `/api` → `http://127.0.0.1:8000`（changeOrigin）
- `/ws` → `ws://127.0.0.1:8000`（ws:true，预留；目前浏览器不可用但配置先留）
- 端口 5173

### 5.7 启动顺序

1. 后端：`uvicorn app.main:app --reload --port 8000`（在 `LoaderCloudBackendV2/master`）
2. 前端：`npm run dev`（在 `LoaderCloudFrontV2`）
3. proxy 自动转 `/api` → 后端

  ↓

  ↓

  ↓

  ↓
Pinia authStore 跨页面共享 token

## 七、实时性方案

- **运行详情大盘**：运行中 5s 轮询 `GET /metrics/timeseries?start=run.start_time&end=now`，滚动展示自场景开始时间起的全程多 label 曲线；翻终态后按 `start_time~end_time` 查一次并停止轮询
- **不接 WS**：后端 `/ws/agent` 是 Agent 专用，浏览器不可连；前端无浏览器侧 WS 端点
- **未来扩展**：若需秒级推送，后端新增 `/ws/runs/{run_no}`（仅广播该 run 的 timeseries），前端用 `new WebSocket` 接入，替换轮询
